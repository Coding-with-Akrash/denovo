    🆘 Help & Documentation

    Getting Started

    Enter your protein sequence in FASTA format. Optionally provide a name and target length. Additional reference files can be uploaded.

    FASTA Format

    Use standard FASTA format:
    >Protein_Name
    MVKLWAALLLAAALCLLGAAG...

    Keyboard Shortcuts

    • Ctrl+Enter: Submit form

    Tips

    • FASTA headers start with >
    • Sequences use standard amino acid codes
    • Multiple sequences can be entered
    • Hover over help icons (?) for field guidance
